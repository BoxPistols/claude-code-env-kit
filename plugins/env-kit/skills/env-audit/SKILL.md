# Claude Code環境の監査

1. このSkillのディレクトリにある`claude-env-audit.py`を実行する。引数は対象のプロジェクトのディレクトリで、省くとカレントディレクトリになる。

   ```
   python3 <このSkillのディレクトリ>/claude-env-audit.py <プロジェクトのディレクトリ>
   ```

2. 出力の表をそのまま示す。「要確認」の行ごとに、直し方の案を1つずつ添える。
3. 直すかどうかは利用者が決める。このSkillの中では設定を書き換えない。
4. チームで共有する設定（リポジトリの`.claude/`）を直す場合は、直す前と後の出力をPRに貼る。

判定の根拠は次の2つ。
- CLAUDE.mdは1ファイル200行未満（公式のmemoryのページ）。10,000バイトの目安はこの監査の独自の基準
- hookの出力は10,000文字が上限（公式のhooksのページ）
