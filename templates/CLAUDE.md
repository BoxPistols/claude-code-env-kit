# プロジェクトの指示

## 止める条件
- 入力が要らない段階は続ける。途中の報告は次の作業と同じメッセージに書く
- 止めて聞くのは、利用者なしでは続けられないときと、データ削除・force push・リポジトリ外の変更の前だけ

## 完了前の検証
- `pnpm typecheck && pnpm lint && pnpm test` が通ることを確かめてから完了とする

## 報告
- 長い作業の最後は「判断待ち」「変更」「発見」の順に書く
- 確かめられなかったことは、どこを見たかを添えて明記する

## 詳しい規則の置き場所
- UIの規則: `.claude/rules/ui.md`（UIのファイルを扱うときに自動で読み込まれる）
